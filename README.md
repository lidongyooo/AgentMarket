# 会干活的 AI 怎么卖

## —— AI Agent 中国市场营销全书

写给 Claude、Codex 类智能体产品的创始人、产品、市场与销售团队。

AI 正在从"能说会道"走向"能干会做"。Agent 承诺的不是"我能回答你的问题"，而是"这件事我替你做完"。承诺越具体，客户的检验就越具体，营销也就越难。本书讨论的是一个具体问题：**在中国市场，如何把"会干活的 AI"卖出去**——从定位、定价、信任建设，到开发者营销、内容与社区、产品驱动增长、企业与政企销售、渠道伙伴，再到品牌、客户成功、度量体系、危机应对和跨境发展。

- 篇幅：4 个部分、19 章，另有 2 个附录和后记，约 14 万汉字
- 每章附有案例、"本章要点"和"行动清单"
- 附录 A 收录了 14 份可直接使用的模板、清单与话术

## 关于本书

- 本书在 AI（Claude）的辅助下撰写完成。
- 书中提到的 Claude、Codex 及国内各类产品，仅用于说明品类特征，不构成对任何产品功能、价格、可用地区的权威描述，产品信息请以厂商官方发布为准。
- 除特别注明的公开事实外，书中案例均为综合化、匿名化的示意案例，人名、公司名为化名，数字为示意性数据，不是行业统计。
- 涉及法律法规与监管要求的内容，仅用于帮助营销团队建立合规意识，具体业务请以最新法规原文和专业律师意见为准。
- 本书不提供任何投资建议。

## 自行构建

统计字数（只需 Python 3）：

```bash
python3 tools/count.py
```

重新生成 Word 版（需要 Node.js）：

```bash
cd tools && npm install && cd ..
node tools/build_docx.js
```

生成的文档使用宋体、黑体、楷体排版。如果本机装有 Microsoft Word，脚本会用 Word 自带的字体估算目录页码；用 Word 打开时选择"更新域"，即可得到准确页码。
