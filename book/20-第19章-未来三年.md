# 第 19 章　未来三年：Agent 营销的趋势与下一步

> 预测未来最好的方式，是看清楚哪些东西会变，哪些东西不会变。

## 19.1 写在趋势之前

AI 行业的变化速度令人目眩。三年前，大多数人还在惊叹于聊天机器人能写诗；今天，编程智能体已经在很多开发团队中成为日常工具，通用智能体能够在云端独立完成复杂的多步骤任务。很难准确预测三年后的 Agent 行业会是什么样子。

本章不试图做精确的预测，而是基于当前的观察，梳理几个大概率会持续发展的趋势，并讨论它们对 Agent 营销意味着什么。更重要的是，我们会讨论在所有变化之中，**哪些东西是不会变的**——那些才是营销人真正应该坚守的东西。

## 19.2 趋势一：从"工具"到"劳动力"

### 趋势描述

Agent 正在从"帮人干活的工具"演进为"能独立承担工作的数字劳动力"。随着模型能力的提升、工具生态的丰富、安全机制的完善，Agent 能够独立完成的任务越来越复杂、运行的时间越来越长、承担的责任越来越大。

这一趋势的标志包括：

- Agent 能够连续工作的时间越来越长，从几分钟到几小时，甚至更长；
- Agent 能够处理的任务从单一步骤扩展到跨系统、跨部门的复杂流程；
- 企业开始以"岗位"而不是"工具"的视角来规划 Agent 的部署；
- 按结果计费、按岗位计费的商业模式越来越普遍。

### 对营销的影响

- **定位**：岗位定位法（第 4 章）将成为主流。营销信息将越来越多地以"它能承担什么岗位""它能交付什么结果"来表达。
- **定价**：按结果计价、按岗位计价将越来越普遍（第 5 章）。营销人需要更熟练地与客户讨论价值和 ROI。
- **购买者**：Agent 的购买决策将越来越多地涉及人力资源、组织规划等部门，而不仅仅是 IT 部门。营销对象需要扩展。
- **社会议题**：随着 Agent 承担越来越多的工作，"AI 与就业"的社会讨论将更加激烈。营销人需要更加谨慎地处理替代叙事，更加重视赋能、解放、协作的叙事（第 14 章）。

## 19.3 趋势二：多 Agent 协作与"向 Agent 营销"

### 趋势描述

未来的工作场景中，可能不是一个 Agent 在干活，而是多个 Agent 协作：一个负责规划的 Agent 把任务分配给多个专业 Agent，它们各自完成自己的部分，再汇总结果。Agent 之间的通信协议、协作标准正在被探索和建立。

更有意思的是，**Agent 将越来越多地成为"购买者"和"选择者"**。当一个 Agent 需要完成某个任务时，它会自主地选择使用哪个工具、调用哪个 API、连接哪个数据源。比如，一个编程智能体在开发一个应用时，需要选择使用哪个数据库服务、哪个支付接口、哪个地图服务；一个研究智能体在撰写报告时，需要选择查询哪个数据库、引用哪个信息源。

### 对营销的影响：B2A 营销

这带来了一个全新的营销概念：**面向 Agent 的营销**（Business to Agent，可以简称为 B2A）。

当 Agent 成为工具和服务的选择者时，营销的对象就不仅仅是人，还包括 Agent。而 Agent 的"决策逻辑"与人完全不同：

- Agent 不看广告，不受品牌形象的影响；
- Agent 会阅读文档、接口说明、工具描述；
- Agent 会评估工具是否能够完成任务、是否稳定可靠、使用是否方便；
- Agent 会根据过往的使用经验（如果有记忆机制的话）做出选择。

因此，面向 Agent 的营销，核心是：

- **高质量的机器可读文档**：清晰、准确、结构化的接口文档和工具描述，让 Agent 能够准确理解你的工具能做什么、怎么用。
- **标准化的接入方式**：支持主流的标准协议（如 MCP），让 Agent 能够方便地发现和使用你的服务。
- **稳定可靠的服务**：Agent 对错误的容忍度很低，不稳定的服务会被 Agent "抛弃"。
- **清晰的错误信息**：当出现问题时，提供清晰的错误信息，让 Agent 能够理解问题并采取相应的措施。
- **合理的计费方式**：Agent 可能会频繁调用你的服务，计费方式要适合 Agent 的使用模式。

在第 7 章，我们说"文档即营销"。在 B2A 的时代，这句话的含义更加深刻：**你的文档不仅是写给人看的，也是写给 Agent 看的**。一个工具的文档质量，可能直接决定 Agent 是否会选择它。

对于开发者工具、API 服务、数据服务、云服务等领域的公司来说，B2A 营销可能在未来几年成为一个重要的竞争维度。

## 19.4 趋势三：终端与系统级 Agent 的入口之争

### 趋势描述

手机、电脑、汽车、智能家居等终端设备的厂商，正在把 Agent 能力集成到操作系统层面。用户只需要说一句话，系统级 Agent 就能够跨应用完成任务：订餐、打车、订票、发消息、整理文件、设置提醒……

在中国，各大手机厂商都在积极推进"手机智能体"，超级应用也在把 AI 助手作为核心战略。系统级 Agent 和超级应用 Agent 之间、不同厂商的 Agent 之间，正在展开一场"入口之争"。

### 对营销的影响

- **入口变化**：用户获取服务的入口可能从"打开某个应用"变为"告诉 Agent 我要做什么"。如果你的服务不能被系统级 Agent 调用，可能就会失去被用户使用的机会。
- **Agent 就绪**：各类应用和服务需要变得"Agent 就绪"（Agent-ready）——提供能够被 Agent 调用的接口，让 Agent 能够代替用户完成操作。
- **品牌弱化的风险**：当用户通过 Agent 使用服务时，可能不再关心是哪个品牌在提供服务，品牌的存在感可能被削弱。如何在 Agent 中介的时代保持品牌的存在感，是一个新的挑战。
- **平台关系**：与终端厂商、超级应用的合作关系将变得更加重要（第 9 章）。

## 19.5 趋势四：垂直深化，行业知识成为壁垒

### 趋势描述

随着通用 Agent 能力的普及，Agent 的竞争将越来越多地转向垂直行业。在每一个垂直行业中，真正的壁垒不是通用的 AI 能力，而是**行业知识**：对行业流程的深入理解、对行业数据的积累、对行业规则的把握、对行业客户的服务经验。

在中国，制造、能源、金融、医疗、教育、政务、零售、物流等行业都有巨大的 Agent 应用空间，也都有各自独特的行业知识门槛。

### 对营销的影响

- **行业化营销**：营销将越来越行业化。针对不同行业的营销内容、销售团队、解决方案、客户案例将成为标配。
- **专家化团队**：营销和销售团队需要更多具有行业背景的专家。
- **行业生态**：与行业软件厂商、行业服务商、行业协会的合作将更加重要（第 13 章）。
- **案例的价值**：行业标杆案例的价值将进一步提升。

## 19.6 趋势五：治理体系成熟，"可审计"成为卖点

### 趋势描述

随着 Agent 在企业和社会中的广泛应用，围绕 Agent 的治理体系将逐步成熟：

- **监管体系**：各国关于 AI 的法规将更加完善，可能出现专门针对 Agent 的监管要求，比如对自主操作的限制、对责任归属的规定、对透明度的要求。
- **标准体系**：关于 Agent 安全、Agent 能力评估、Agent 互操作性的标准将陆续出台。
- **认证体系**：可能出现针对 Agent 产品的安全认证、能力认证。
- **审计体系**：企业将需要对其使用的 Agent 进行审计，第三方 Agent 审计服务可能兴起。

### 对营销的影响

- **"可审计"成为卖点**：能够提供完整的操作记录、决策依据、权限管理、合规报告的 Agent，将在企业市场中获得明显优势。
- **合规能力的价值提升**：正如我们在全书中反复强调的，合规不是成本，而是护城河。随着治理体系的成熟，这一点将更加明显。
- **标准的话语权**：参与标准制定的企业将获得更多的话语权和信任。
- **认证的重要性**：获得权威认证将成为进入特定市场的门票。

## 19.7 趋势六："人 + Agent"的组织变革

### 趋势描述

随着 Agent 的普及，企业的组织形态将发生深刻的变化：

- **新的团队结构**：团队将由人和 Agent 共同组成，一个人可能管理多个 Agent。
- **新的岗位**：将出现新的岗位，比如负责设计和管理 Agent 工作流程的人、负责训练和优化 Agent 的人、负责审核 Agent 工作成果的人。
- **新的技能要求**：员工需要掌握与 Agent 协作的技能——描述任务、设定边界、审核结果、给出反馈（第 1 章所说的"AI 管理者"能力）。
- **新的管理方式**：企业需要新的方式来管理和评估"人 + Agent"团队的绩效。

### 对营销的影响

- **营销对象的变化**：Agent 的使用者将越来越多地是"Agent 管理者"，他们的需求和关注点与传统的软件用户不同。
- **用户教育的重要性**：帮助企业和员工完成组织变革、掌握新技能，将成为 Agent 营销的重要组成部分。培训、认证、最佳实践、变革管理咨询将成为重要的营销手段。
- **变革管理能力**：能够帮助客户进行组织变革的 Agent 公司，将在竞争中占据优势（第 11 章、第 15 章）。

## 19.8 趋势七：营销团队自身的 Agent 化

### 趋势描述

最后一个趋势，与营销人自身密切相关：**营销工作本身正在被 Agent 重塑**。

内容创作、数据分析、客户研究、竞品监测、广告投放优化、销售线索管理、客户沟通……营销工作中的大量任务，都可以由 Agent 来完成或辅助完成。一个小型的营销团队，借助 Agent 可能能够完成过去需要一个大团队才能完成的工作。

### 对营销人的影响

- **技能升级**：营销人需要学会与 Agent 协作，成为"营销 Agent 的管理者"。
- **价值重心转移**：营销人的价值将越来越多地体现在 Agent 难以替代的方面：战略思考、创意洞察、人际关系、品牌判断、伦理把关。
- **吃自己的狗粮**：对于 Agent 公司的营销团队来说，用自己的 Agent 做营销，既是提升效率的方式，也是最好的产品演示（第 8 章）。
- **合规意识**：使用 Agent 生成营销内容时，需要遵守 AI 生成内容标识等相关规定。

## 19.9 不变的东西

在讨论了这么多变化之后，让我们回到一个更根本的问题：**在所有的变化之中，什么是不变的？**

### 不变之一：信任

无论 Agent 变得多么强大，客户把工作托付给 Agent 的前提永远是信任。能力越强、自主程度越高、承担的责任越大，信任就越重要。**信任是 Agent 的第一产品**，这一点在未来只会更加真实。

### 不变之二：价值

客户购买 Agent，永远是为了获得价值——节省时间、降低成本、提高质量、创造收入。技术会变，形态会变，但"为客户创造价值"这一营销的根本不会变。**卖的是被完成的工作，而不是被提供的能力。**

### 不变之三：诚实

在一个充满夸大宣传的行业中，诚实是最稀缺、也最有价值的品质。诚实的演示、诚实的宣传、诚实的价值报告、诚实地面对错误——这些做法在短期内可能显得"不够激进"，但长期来看，它们是建立品牌信任的唯一途径。

### 不变之四：以客户为中心

无论技术如何变化，营销的起点永远是客户：客户是谁、客户需要什么、客户担心什么、客户如何做决策。深入理解客户，是一切营销工作的基础。

### 不变之五：长期主义

Agent 行业充满了诱惑：追逐热点、制造爆款、快速融资、快速扩张。但真正能够穿越周期的公司，是那些坚持长期主义的公司：持续打磨产品、持续服务客户、持续建设信任、持续积累行业知识。

## 19.10 给不同角色的建议

最后，给不同角色的读者一些具体的建议：

### 给创始人

- 尽早明确你的主攻客户和核心场景，抵抗"万能的诅咒"。
- 把信任和合规作为战略来经营，而不是事后补救。
- 亲自参与营销和销售，尤其是在早期。你的声音是公司最重要的品牌资产。
- 坚持长期主义，不要为了短期的增长牺牲长期的信任。

### 给市场负责人

- 深入理解你的产品，能够回答"Agent 素养清单"中的所有问题。
- 把诚实作为营销的底线，坚持诚实的演示和宣传。
- 建立以"被采纳的完成任务数"为核心的度量体系。
- 学会使用 Agent 做营销，成为营销 Agent 的管理者。

### 给销售负责人

- 从"签单"思维转变为"上岗"思维，以 Agent 稳定干活为终点设计销售流程。
- 诊断先行，帮助客户选对第一个场景，首战必胜。
- 与交付和客户成功团队紧密协作。
- 在政企市场坚守合规与廉洁的底线。

### 给产品负责人

- 把首个完成任务率作为核心指标，持续优化新用户的激活体验。
- 把"看得见、管得住、撤得回"作为产品设计的核心原则。
- 降低用户的监督成本，让 Agent 的价值更容易被感知。
- 为 B2A 时代做准备：让你的产品既能被人使用，也能被 Agent 使用。

### 给开发者关系与社区负责人

- 从"营销"转向"服务"，用真正有价值的内容赢得开发者。
- 建设真诚的社区，培养超级用户。
- 拥抱开放标准，在生态中找到自己的位置。

### 给客户成功负责人

- 用"员工职业生涯"的视角管理 Agent 在客户那里的生命周期。
- 重视入职准备，帮助客户准备好 Agent 的"入职材料"。
- 让价值被看见，帮助发起者在内部证明价值。
- 关注模型升级、效果漂移、知识库维护等 Agent 特有的挑战。

---

## 本章要点

1. 趋势一：Agent 从"工具"演进为"劳动力"，岗位定位和按结果计价将成为主流，要更加谨慎地处理替代叙事。
2. 趋势二：多 Agent 协作兴起，Agent 将成为工具和服务的"选择者"，催生面向 Agent 的营销（B2A）。文档不仅写给人看，也写给 Agent 看。
3. 趋势三：终端与系统级 Agent 的入口之争，服务需要"Agent 就绪"，品牌存在感面临挑战。
4. 趋势四：垂直深化，行业知识成为壁垒，营销将更加行业化。
5. 趋势五：治理体系成熟，"可审计"成为卖点，合规能力的价值进一步提升。
6. 趋势六："人 + Agent"的组织变革，用户教育和变革管理能力将成为重要的竞争力。
7. 趋势七：营销团队自身的 Agent 化，营销人需要成为营销 Agent 的管理者。
8. 不变的东西：信任、价值、诚实、以客户为中心、长期主义。
