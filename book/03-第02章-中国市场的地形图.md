# 第 2 章　中国市场的地形图：政策、生态与竞争格局

> 好的营销从来不是在真空里设计出来的。在中国做 Agent 营销，你首先要看懂脚下的地形。

## 2.1 三年三个关键词：从"百模大战"到"智能体落地"

要理解今天中国 Agent 市场的格局，需要先回顾一下这几年行业走过的路。我们可以用三个关键词来概括。

### 关键词一：百模大战

2023 年，大模型热潮席卷中国。互联网大厂、AI 公司、高校研究机构、创业团队纷纷发布自己的大模型，一时间"百模大战"成为行业热词。这一阶段的营销主题是"我也有"：证明自己具备大模型能力，在各类基准测试榜单上争排名，在发布会上展示对话能力。

这一阶段为后来的 Agent 市场留下了两份遗产。第一份是**用户的初步认知**：大量普通用户第一次接触到了能对话、能写作的 AI。第二份是**监管框架的建立**：2023 年下半年起，《生成式人工智能服务管理暂行办法》正式施行，面向公众提供生成式 AI 服务的备案制度逐步落地，为此后所有 AI 产品划定了基本的合规轨道。

### 关键词二：价格战与开源潮

2024 年，行业的竞争焦点从"有没有"转向"用不用得起"。年中前后，以 DeepSeek 为代表的厂商将模型 API 价格降到极低水平，随后字节、阿里、百度、腾讯等大厂纷纷跟进大幅降价，部分轻量模型甚至直接免费。与此同时，国产开源模型快速崛起，通义千问、DeepSeek 等开源模型系列在全球开发者社区获得了广泛关注和使用。

价格战和开源潮对 Agent 市场的影响极其深远。它带来的直接结果是：**模型调用成本大幅下降，构建 Agent 的门槛大幅降低。**一个小团队也可以用很低的成本调用强大的模型，开发自己的 Agent 应用。这在客观上催生了大量 Agent 创业公司，也让"模型能力"本身越来越难成为差异化卖点。

### 关键词三：智能体落地

2025 年是中国 AI 行业极具戏剧性的一年。年初，DeepSeek 推理模型在春节前后迅速出圈，各大应用商店排名飙升，"AI"真正成为全民话题——从大学生到退休老人，从县城小老板到地方政府，几乎所有人都在讨论 AI。这次出圈完成了一次规模空前的"全民市场教育"。

紧接着，Manus 等通用智能体产品的发布在国内引发热议，邀请码一度一码难求。不论后续评价如何，它让"Agent"这个词第一次进入了大众舆论场。此后，Kimi、智谱、阿里、字节、MiniMax 等厂商陆续发布了强调智能体能力、编程能力的新一代模型，各类 AI 编程工具在开发者群体中快速普及，"智能体"成为几乎所有 AI 公司发布会上的核心词汇。

在国家层面，"人工智能+"行动自 2024 年政府工作报告提出后持续推进，2025 年国务院印发了关于深入实施"人工智能+"行动的指导文件，把智能体等新形态的规模化应用作为重要方向。地方政府也纷纷出台配套政策，算力券、模型券、应用场景开放等举措层出不穷。

到今天，行业的主题已经从"展示能力"切换为"落地价值"。客户不再满足于看演示，而是问："在我的业务里，能替我干什么？能省多少？出了问题谁负责？"这正是本书要回答的问题。

### 对营销的三点启示

回顾这段历程，有三点启示值得营销人记住：

1. **市场教育的成本已经被行业分摊了。**今天绝大多数中国用户和企业都"知道"AI，你不需要再从"什么是大模型"讲起。你需要做的是从"知道"推进到"用上"，从"用上"推进到"离不开"。
2. **模型能力正在快速同质化。**价格战和开源潮让强大的模型能力变得随处可得。如果你的营销只讲"我们用了最强的模型"，你很快会发现这句话没有任何区分度。
3. **政策是顺风，但也有边界。**国家大力推动 AI 应用落地，这为 Agent 产品带来了大量政策红利和场景机会；同时，监管框架也在持续完善，合规能力会成为越来越重要的竞争要素。

## 2.2 政策地形：营销人必须知道的规则

很多营销人对法规的态度是"那是法务的事"。在 Agent 领域，这种态度会让你付出代价。下面我们从营销视角梳理与 Agent 产品最相关的规则，重点不是法条本身，而是**它们如何影响你能说什么、怎么说、对谁说**。

> 提示：法规在持续更新，以下内容用于建立合规意识，具体执行请以最新法规原文和专业法律意见为准。

### 第一层：生成式 AI 专门监管

**《生成式人工智能服务管理暂行办法》**（2023 年 8 月起施行）是面向公众提供生成式 AI 服务的基础性规定。它对训练数据来源、内容安全、用户权益保护、服务透明度等提出了要求。

**备案与登记制度**：面向境内公众提供具有舆论属性或社会动员能力的生成式 AI 服务，需要完成相应的备案；通过 API 调用已备案模型、面向公众提供服务的应用，通常也需要履行登记等手续。网信部门会定期公布已完成备案和登记的服务名单。

> **对营销的影响**：备案或登记情况是企业客户、尤其是政企客户在采购时高度关注的问题。"已完成备案/登记"本身就是一个有分量的信任信号，可以在官网、销售资料、招投标文件中规范呈现。反过来，如果你的产品尚未完成相应手续，就要非常谨慎地评估面向公众推广的方式和范围。

**算法推荐与深度合成相关规定**：如果你的 Agent 涉及向用户推荐信息，或者生成、编辑图像、音频、视频等内容，还需要关注算法推荐管理和深度合成管理的相关要求，比如算法备案、显著标识等。

**《人工智能生成合成内容标识办法》**（2025 年 9 月起施行）及配套的强制性国家标准，要求对 AI 生成合成的文本、图片、音频、视频、虚拟场景等内容进行显式标识和（或）隐式标识。

> **对营销的影响**：这一点常被忽视。首先，你的 Agent 产品本身如果面向公众生成内容，需要落实标识要求，这应该成为你产品合规能力的一部分，并可以作为"负责任 AI"的卖点。其次，**你在营销中使用 AI 生成的素材**——比如用 AI 生成的宣传视频、海报、配音、数字人——也需要遵守标识要求。一家宣传自己"合规领先"的 AI 公司，如果自己的营销素材没有按规定标识，会非常尴尬。

### 第二层：数据与个人信息

**《个人信息保护法》《数据安全法》《网络安全法》**构成了数据合规的基本框架。对于 Agent 产品来说，以下几个问题尤其突出：

- **Agent 会接触哪些数据？**Agent 的工作需要读取文件、邮件、聊天记录、业务数据，这些数据中往往包含个人信息甚至敏感个人信息。
- **数据会被用于训练吗？**这是企业客户最常问的问题之一。你的服务协议和隐私政策如何约定？默认设置是什么？企业版是否承诺不用于训练？
- **数据存在哪里？是否出境？**如果你的 Agent 调用了境外模型，或者数据会传输到境外服务器，就涉及数据出境的合规要求，包括安全评估、标准合同、个人信息保护认证等路径。
- **网络安全等级保护**：面向企业，尤其是金融、政务、能源等关键行业客户时，等级保护测评情况往往是准入门槛。

> **对营销的影响**：数据问题是 Agent 营销的"第一道坎"。我们建议你准备一份**数据流向说明**——用一张图、一页纸，清楚说明用户数据从哪里来、经过哪里、存在哪里、谁能访问、保存多久、是否用于训练。这份材料在第 6 章会详细展开。

### 第三层：广告与宣传

这是营销人最直接面对、也最容易"踩雷"的一层。

**《广告法》**的几条规定对 AI 产品营销影响很大：

- **禁止使用绝对化用语**，如"国家级""最高级""最佳"等。AI 行业的营销文案里，"最强""第一""最聪明""全球领先"随处可见，这些表述都有法律风险。即使是"在某某榜单排名第一"这样有依据的表述，也应该注明具体榜单、时间和范围，并确保可以证明。
- **禁止虚假或引人误解的宣传**。如果你宣传"Agent 可以完全替代人工""效率提升十倍"，就必须有真实、可证明的依据，并且不能以偏概全。
- **对效果的承诺需要格外谨慎**。尤其是在教育、金融、医疗等特殊领域，相关法规对效果承诺有更严格的限制。

**《反不正当竞争法》**（2025 年完成修订）同样禁止虚假或引人误解的商业宣传，也对贬损竞争对手的商业信誉等行为作出了规定。在 AI 行业常见的"对标营销"——比如"我们比某某产品强多少"——必须建立在客观、可验证的对比基础上，不能断章取义，也不能贬低对手。

**《互联网广告管理办法》**（2023 年 5 月起施行）要求互联网广告具有可识别性，"软文"、带货内容、KOL 合作推广等需要显著标明"广告"字样。这对于依赖 KOL、知识博主进行推广的 Agent 产品来说尤其重要。

> **对营销的影响**：建立一份**营销用语红线清单**，所有对外文案上线前过一遍。我们在附录 A 中提供了一份可以参考的清单模板。

### 第四层：行业与采购规则

如果你的目标客户是金融、医疗、教育、政务、能源等行业，还需要了解各行业主管部门对 AI 应用的专门指导意见和准入要求。如果你要参与政府和国有企业的采购，还需要了解政府采购、招标投标的相关规则，以及信创（信息技术应用创新）相关要求。这部分内容将在第 12 章详细讨论。

### 一张表看懂政策对营销的影响

| 规则领域 | 核心关注点 | 对营销的直接影响 | 营销可以做的事 |
|---|---|---|---|
| 生成式 AI 管理与备案 | 服务合规、内容安全 | 影响能否面向公众推广、政企客户准入 | 规范展示备案/登记信息，作为信任信号 |
| AI 生成内容标识 | 显式与隐式标识 | 产品输出需标识；营销素材也需标识 | 把标识能力作为"负责任 AI"卖点；自查营销素材 |
| 个人信息与数据安全 | 数据收集、使用、存储、出境 | 客户最核心的顾虑 | 准备数据流向说明；明确训练数据政策 |

## 2.3 生态地形：在超级平台之间找到位置

中国的数字生态有一个鲜明特点：**高度平台化**。少数几个超级平台掌握着用户的大部分时间和注意力，也掌握着大量的流量分发权。对 Agent 产品来说，理解这些平台的格局至关重要。

### 五类关键生态参与者

**1. 超级应用平台。**微信、抖音、支付宝、淘宝等超级应用拥有数亿乃至十亿级的用户。它们都在积极布局 AI 能力，把 AI 助手和智能体嵌入到自己的生态中。对于独立 Agent 产品来说，这些平台既是潜在的流量入口（例如微信生态里的小程序、公众号、视频号），也是潜在的竞争对手（平台自己的 AI 助手可能覆盖你的场景）。

**2. 大模型与云厂商。**阿里、字节、腾讯、百度、华为等大厂既有自己的大模型，又有云计算业务，还有面向开发者的智能体开发平台。它们是 Agent 生态的"基础设施提供者"，同时也通过自有产品直接参与应用层竞争。DeepSeek、月之暗面（Kimi）、智谱、MiniMax、阶跃星辰等模型公司也在构建自己的产品和生态。

**3. 办公协同平台。**钉钉、飞书、企业微信是中国企业数字化办公的三大入口，覆盖了大量企业用户。它们都在把 AI 助手和智能体作为核心战略，并开放了智能体接入能力。对于面向企业的 Agent 产品来说，**接入这三大平台往往是触达企业用户的最短路径**，"在钉钉/飞书/企业微信里直接用"是一个非常有力的卖点。

**4. 终端厂商。**华为、小米、荣耀、OPPO、vivo 等手机厂商，以及电脑厂商，都在系统层面集成 AI 助手，推动"手机智能体"——用户说一句话，手机上的 AI 就能跨应用完成订票、点餐、发消息等操作。终端厂商掌握着设备入口，是 C 端 Agent 不可忽视的力量。

**5. 垂直行业平台与软件厂商。**各行业的 ERP、CRM、HR、财务软件厂商，以及电商平台、内容平台、本地生活平台，都在把 AI 能力融入自己的产品。它们既可能是 Agent 产品的渠道伙伴，也可能是竞争对手。

### 平台依赖的双刃剑

对于 Agent 产品来说，平台是一把双刃剑。

**依附平台的好处**：获得流量入口，降低用户获取成本；借用平台的账号体系、支付体系、信任背书；用户在熟悉的环境里使用，降低学习成本。

**依附平台的风险**：平台规则变化可能让你一夜之间失去流量；平台可能推出自有产品替代你；用户关系掌握在平台手里，难以建立自己的品牌和私域；平台抽成会压缩利润空间。

我们的建议是采用**"借船出海、自建码头"**的策略：在早期积极借助平台获取用户和建立认知，同时从第一天起就有意识地建设自己的用户关系资产——官网、自有账号体系、开发者社区、私域社群、企业客户的直接合同关系。当平台规则变化时，你仍然有自己的码头可以停靠。

## 2.4 竞争地形：四类玩家与一个"影子对手"

### 四类主要玩家

**第一类：大厂全栈型。**拥有模型、云、应用、流量、生态的全栈能力。它们的优势是资源雄厚、入口众多、能够承受长期投入和价格战；劣势是组织复杂、决策链长、对细分场景的打磨可能不够深入、产品之间可能存在内部竞争。

**第二类：模型创业公司。**以模型能力为核心竞争力，同时向应用层延伸，推出自己的助手产品、编程工具或智能体产品。它们的优势是技术领先、品牌有技术光环；劣势是需要在模型研发和产品商业化之间平衡资源，面临大厂的直接竞争。

**第三类：Agent 应用创业公司。**不自研基础模型，而是基于开源或商用模型，专注于某类场景或某个行业构建 Agent 产品。它们的优势是对场景理解深、迭代快、灵活；劣势是技术壁垒相对较低，容易被模仿，也面临模型厂商"向上吃掉应用层"的风险。

**第四类：传统软件转型者。**原本做 CRM、ERP、OA、客服、财务、法务等企业软件的公司，把 Agent 能力融入现有产品。它们的优势是拥有客户基础、行业知识、数据和交付能力；劣势是技术和组织转型的难度大，原有产品的商业模式可能与 Agent 模式冲突。

### 一个"影子对手"：海外标杆产品

在中国 Agent 市场的竞争中，有一类特殊的存在：Claude、Codex、ChatGPT、Cursor 等海外标杆产品。

需要明确的是，Anthropic、OpenAI 等海外头部模型厂商目前并未在中国大陆正式提供服务，其中部分厂商还对中国资本控股的企业设置了明确的服务限制。因此，它们在中国市场并不是一个"可以正常购买"的竞争选项。

但它们是一个**影子对手**，在三个层面深刻影响着中国市场：

1. **品类定义者**。很多 Agent 品类的产品形态和用户期望，是由海外标杆产品首先定义的。比如"在终端里工作的编程智能体""在云端沙箱里异步完成任务的编程智能体""能连接外部工具的标准协议"等概念，国内开发者和从业者往往是通过这些产品首先认识的。
2. **期望设定者**。国内的技术用户会天然地拿国内产品与海外标杆比较。"和 Claude 比怎么样？""能不能达到 Codex 的水平？"这类问题在开发者社区里非常常见。
3. **叙事参照系**。媒体和投资人常常用"中国版 XX"来描述国内产品。这种参照既能帮你快速建立认知，也可能让你永远活在别人的影子里。

> **营销策略提示**：对标海外标杆是一把双刃剑。在早期，借用标杆产品的品类认知可以降低沟通成本，比如"我们是一款在终端里工作的编程智能体"，开发者一听就懂。但要避免把"中国版 XX"作为核心定位——它会让客户默认你是追随者，并且在每一次对比中都处于被审视的位置。更好的做法是：**借用品类认知，建立自己的差异点**。比如，强调对中文语境和国内技术栈的深度适配、对国内开发平台和办公平台的原生集成、本地化部署能力、合规能力、本地服务能力等海外产品难以提供的价值。

### 竞争格局的三个趋势

**趋势一：模型层同质化，竞争上移。**随着开源模型的成熟和价格战的持续，模型本身的差异在大多数应用场景中正在缩小。竞争的焦点正在从"谁的模型更强"上移到"谁的产品更好用""谁更懂行业""谁的交付能力更强""谁的生态更丰富"。

**趋势二：大厂与创业公司的边界不断变化。**大厂在不断推出新的 Agent 产品，覆盖越来越多的场景；创业公司则在寻找大厂不愿做、做不好或做不快的细分场景。这种边界每隔几个月就会发生变化，营销人需要持续追踪。

**趋势三：从"单兵作战"到"生态协作"。**随着标准协议的普及，Agent 之间、Agent 与工具之间的连接变得越来越容易。未来的竞争可能不是单个 Agent 之间的竞争，而是 Agent 生态之间的竞争。谁能连接更多的工具、更多的数据、更多的伙伴，谁就更有优势。

## 2.5 中国 Agent 市场的五个结构性特征

综合政策、生态和竞争三层地形，我们可以总结出中国 Agent 市场的五个结构性特征。这五个特征是制定营销策略的基础假设。

### 特征一：免费心智强，付费分层明显

中国 C 端用户长期习惯于免费使用互联网服务，加上大厂 AI 助手普遍免费，"AI 应该是免费的"已经成为大众用户的普遍心智。但与此同时，付费意愿在不同群体之间分化明显：开发者、内容创作者、专业人士、中小企业主对能直接带来收益或节省时间的工具，付费意愿并不低。

**营销含义**：C 端大众市场不宜作为大多数 Agent 创业公司的主战场；应聚焦于"愿意为效率付费"的专业人群和企业。免费策略要精心设计，避免陷入"免费用户越多、亏损越大"的困境。

### 特征二：私有化与本地部署偏好

相比海外市场，中国企业客户——尤其是大中型企业、金融机构、国央企和政府机构——对私有化部署、本地部署有更强的偏好。原因包括数据安全顾虑、合规要求、对外部云服务的信任程度、以及传统的 IT 采购习惯。

**营销含义**：面向企业市场的 Agent 产品，通常需要具备私有化部署能力，或者至少提供专属部署、混合部署等选项。"支持私有化部署""支持国产算力"往往是进入大客户的门票。同时，私有化部署会显著影响定价模式和交付成本，需要提前规划。

### 特征三：入口高度集中

用户的注意力集中在少数超级平台，企业的办公集中在少数协同平台。独立产品获取用户的成本越来越高。

**营销含义**：渠道策略中必须认真考虑平台合作——接入办公协同平台、上架云市场、与终端厂商合作、在超级应用生态内构建入口。同时要警惕过度依赖。

### 特征四：开源繁荣，模仿迅速

国产开源模型的繁荣，让构建 Agent 的技术门槛不断降低。一个产品创新出现后，往往在几周内就会出现大量模仿者。

**营销含义**：不能把"技术独特性"作为长期壁垒来营销。真正的壁垒来自于品牌信任、客户关系、行业数据积累、交付经验和生态网络。营销要服务于这些长期壁垒的建设。

### 特征五：政策驱动的场景开放

"人工智能+"行动和各地配套政策，为 Agent 产品在政务、制造、能源、交通、医疗、教育等领域打开了大量应用场景。许多地方政府和国有企业有明确的 AI 应用推进任务和预算。

**营销含义**：政策是重要的市场信号和机会来源。营销团队需要跟踪中央和地方的政策动态，把握"示范项目""标杆场景""揭榜挂帅"等机会。但也要注意，政策驱动的需求可能存在"重示范、轻实效"的风险，要以真实价值为本，避免成为"盆景项目"。

## 2.6 绘制你自己的地形图

最后，我们提供一个简单的工具，帮助你绘制自己产品的"市场地形图"。

### 工具：双轴定位法

以"**政策敏感度**"为横轴，以"**平台依赖度**"为纵轴，把你的目标市场分为四个象限：

- **低政策敏感、低平台依赖**（例如：面向开发者的编程工具、面向海外市场的产品）：营销自由度最高，可以快速试错，重点在于产品口碑和社区建设。
- **低政策敏感、高平台依赖**（例如：基于办公协同平台的效率 Agent、超级应用生态内的 Agent 小应用）：重点在于平台合作和平台内运营，同时要建设自有用户资产。
- **高政策敏感、低平台依赖**（例如：金融、医疗、政务领域的私有化 Agent 解决方案）：重点在于资质、合规、标杆案例和直销能力，营销周期长但壁垒高。
- **高政策敏感、高平台依赖**（例如：面向公众的内容生成类 Agent、面向 C 端的金融或健康助手）：难度最大，需要同时管理监管风险和平台风险，对合规能力要求最高。

把你的产品放进这张图里，你就能大致判断营销资源应该优先投向哪里。

### 地形图检查清单

在制定年度营销计划之前，建议团队一起回答以下问题：

1. 我们的产品是否需要完成生成式 AI 服务备案或登记？目前进展如何？
2. 我们使用的模型来源是什么？是否涉及境外模型或数据出境？
3. 我们的产品输出是否需要落实 AI 生成内容标识？我们的营销素材是否合规标识？
4. 我们的目标客户所在行业有哪些特殊的准入要求？
5. 我们依赖哪些平台获取用户？如果其中一个平台规则变化，影响有多大？
6. 我们最主要的三个竞争对手分别属于哪一类玩家？他们的优势和短板是什么？
7. 有没有大厂可能在未来半年内推出覆盖我们核心场景的产品？我们的应对是什么？
8. 有哪些中央和地方政策与我们的目标市场相关？有哪些可以利用的政策机会？

## 本章要点

1. 中国 AI 市场经历了"百模大战—价格战与开源潮—智能体落地"三个阶段。市场教育已被行业分摊，模型能力快速同质化，营销焦点应从"展示能力"转向"落地价值"。
2. 政策地形分为四层：生成式 AI 专门监管、数据与个人信息、广告与宣传、行业与采购规则。合规不只是法务的事，它直接约束营销的内容和方式，也能成为信任信号。
3. 生态地形高度平台化。建议采用"借船出海、自建码头"的策略：借助平台获客，同时建设自有用户资产。
4. 竞争地形中有大厂全栈型、模型创业公司、Agent 应用创业公司、传统软件转型者四类玩家，还有海外标杆产品这一"影子对手"。借用品类认知，但不要把"中国版 XX"作为核心定位。
5. 中国 Agent 市场有五个结构性特征：免费心智强而付费分层、私有化偏好、入口集中、开源繁荣而模仿迅速、政策驱动场景开放。
