## A1　Agent 岗位说明书模板

（对应第 4 章）

| 项目 | 填写说明 | 你的填写 |
|---|---|---|
| 岗位名称 | 用客户熟悉的语言，例如"供应商对账专员""缺陷修复工程师" | |
| 服务对象 | 它为谁工作，向谁汇报 | |
| 核心职责 | 三到五项具体工作，每项以动词开头 | |
| 不负责的事 | 明确的边界，至少写三条 | |
| 能力要求 | 它擅长的技能与知识 | |
| 工作权限 | 能访问的数据、能调用的工具、能执行的操作 | |
| 工作方式 | 自主程度、汇报机制、审批节点 | |
| 考核指标 | 两到四个可量化指标 | |
| "薪酬" | 计费方式与大致成本 | |
| 试用期安排 | 试用期时长、试用期任务范围、转正标准 | |

**填写提示**：

1. "不负责的事"往往对应客户最担心的风险，写得越清楚，客户越放心。
2. "考核指标"尽量采用客户业务中已有的指标，便于客户理解和对比。
3. 岗位说明书完成后，请一位目标客户阅读，并请他用自己的话复述这个岗位是做什么的。

## A2　任务地图评分表

（对应第 4 章）

| 候选任务 | 频次（1–5） | 价值（1–5） | 可验证性（1–5） | 容错度（1–5） | 当前完成能力（高/中/低） | 总分 | 结论 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |
| | | | | | | | |
| | | | | | | | |
| | | | | | | | |
| | | | | | | | |

**评分标准**：

- **频次**：每天发生得 5 分；每周发生得 4 分；每月发生得 3 分；每季度发生得 2 分；每年或更少得 1 分。
- **价值**：由资深人员耗时较长完成得 5 分；由普通人员耗时较长完成得 4 分；耗时中等得 3 分；耗时较短得 2 分；几乎不耗时得 1 分。
- **可验证性**：有明确标准答案且可自动检查得 5 分；有明确标准、需人工检查得 4 分；有大致标准得 3 分；主要依赖经验判断得 2 分；完全主观得 1 分。
- **容错度**：出错易发现、易纠正、几乎无损失得 5 分；出错有一定损失但可挽回得 3 分；出错可能造成重大且难以挽回的损失得 1 分。
- **当前完成能力**：低则一票否决，暂不作为核心任务。

**结论分类**：总分 17 分及以上且完成能力为高的，列为"黄金任务"；13–16 分的列为"第二阶段任务"；12 分及以下的暂不作为核心。

## A3　定位语句模板

（对应第 4 章）

> 为【目标客户】，在【具体场景】中，【完成什么任务、交付什么结果】。与【主要替代方案】不同，我们【独特之处】。

**自检问题**：

- 目标客户是否足够具体？（"企业"太宽泛，"年采购额过亿的制造企业财务部"更具体）
- 场景是否是一个黄金任务？
- 结果是否是客户可以感知和验证的？
- 替代方案是否是客户当前真实在用的方式？
- 独特之处是否是竞争对手难以快速复制的？

**一句话介绍提炼原则**：说结果不说技术，说具体不说宏大，说客户的语言不说行业黑话，不使用绝对化用语。

## A4　营销用语红线清单

（对应第 2 章、第 8 章）

> 提示：本清单用于帮助建立合规意识，具体请以最新法规原文和法律意见为准。

### 一、绝对化用语（避免使用）

- 最强、最好、最佳、最先进、最智能、最聪明、最快、最准
- 第一、唯一、首个、独家、顶级、极致、王者、冠军（无可证明依据时）
- 国家级、世界级、全球领先、行业领先（无可证明依据时）
- 100%、零失误、零风险、绝对安全、永不出错

**替代表述**：用具体的数据和条件代替绝对化表述。例如，把"最准确的对账 AI"改为"在 XX 类对账单测试集上，差异识别准确率达到 XX%（测试条件见说明）"。

### 二、效果承诺（谨慎使用）

- "效率提升十倍""节省 90% 成本"等——必须有真实、可证明的依据，并注明条件和范围。
- "完全替代人工""再也不需要 XX 岗位"——容易引发争议，且通常难以证明。
- 在教育、医疗、金融等特殊领域的效果承诺——受到更严格的限制，需特别审慎。

### 三、比较宣传（谨慎使用）

- 与竞争对手的对比必须客观、真实、可验证，注明对比的条件、版本和时间。
- 不得贬低竞争对手，不得断章取义。

### 四、引用与背书

- 引用榜单排名，需注明榜单名称、发布时间和具体范围。
- 使用客户名称和客户证言，需获得客户的正式授权。
- 资质与认证的表述必须准确，"正在申请"不能写成"已获得"。

### 五、广告标识

- KOL 合作内容、付费推广内容需显著标明"广告"，并遵守各平台的商业合作标注规则。

### 六、AI 生成内容标识

- 使用 AI 生成的图片、音频、视频、数字人等营销素材，需按照相关规定进行标识。

## A7　POC 价值报告模板

（对应第 11 章）

1. **执行摘要**（一页以内）：POC 目标、核心结果、建议的下一步。
2. **POC 概况**：场景、范围、参与人员、时间。
3. **成果数据**：各项成功标准的达成情况（目标 vs 实际），以及任务完成量、采纳率、监督时间等过程数据。
4. **价值测算**：基于 POC 数据，测算全面推广后的价值（时间、成本、质量、速度），说明测算方法和假设，采用保守估算。
5. **用户反馈**：一线用户的使用体验与原话摘录（获得同意后）。
6. **问题与改进**：POC 中遇到的问题、已解决的问题、待改进事项。
7. **推广建议**：规模化路线图（横向、纵向、跨部门）、资源需求、预算建议、风险与应对。
8. **附件**：详细数据、典型任务样例、安全与合规材料。

**写作提示**：这份报告是给客户发起者"向上汇报"用的。请确保执行摘要能够被直接复制到客户内部的汇报材料中。

## A13　销售话术库

（对应第 3 章、第 11 章）

### 开场

- "在介绍我们的产品之前，我想先了解一下，您的团队目前在哪些工作上花的时间最多、最希望被解放出来？"
- "很多客户第一次接触 Agent 时，最关心的其实不是它能做什么，而是它会不会搞砸。您这边最担心的是什么？"

### 诊断提问

- "这项工作目前由几个人在做？每周大概花多少时间？"
- "这项工作做得好不好，您现在是怎么判断的？"
- "如果这项工作出了错，最坏的情况是什么？"
- "完成这项工作需要用到哪些系统和数据？"
- "如果这个项目成功了，您最希望在什么场合、向谁汇报这个成果？"

### 价值表达

- "交代一句话，二十分钟后来验收——您只需要花原来十分之一的时间做检查。"
- "我们建议先从一个风险低、见效快的场景开始，让数据说话。"
- "您不需要一开始就完全信任它，我们可以从'只给建议、人来执行'开始。"

### 异议处理（示例）

- **"AI 不靠谱"**："您的担心非常合理。所以我们的设计是：关键操作都需要人确认，所有操作都有记录、可以撤回。我们可以给您演示一下，当 Agent 想做一件高风险的事时，系统是怎么拦住它的。"
- **"数据不能出去"**："完全理解。我们支持完全私有化部署，模型和数据都在您的内网里。这是数据流向图，您可以请信息安全的同事一起看看。"
- **"大厂的免费"**："免费的工具确实很多。我们建议比较的不是价格，而是'您的团队最终需要花多少时间'。我们可以用您的真实任务做一个小测试，对比一下。"
- **"再等等"**："技术确实在快速变化，好消息是我们的产品会随着模型升级自动变强。而团队学会与 Agent 协作需要时间，早开始的团队会积累明显的经验优势。我们可以从一个很小的试点开始。"
