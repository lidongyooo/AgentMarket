# 第四部分　品牌与长期篇：做一家值得托付的 Agent 公司

---

# 第 14 章　品牌叙事：给 AI 一个可信的"人设"

> 功能可以被复制，价格可以被追平，但一个被信任的品牌，需要很多年才能被替代。

## 14.1 为什么 Agent 公司需要品牌

在 AI 行业，很多人认为品牌不重要："技术才是硬道理""产品好自然有人用"。这种观点在技术快速迭代的早期有一定道理：当一家公司的技术明显领先时，用户会自然而然地涌向它。

但随着行业的成熟，这种观点越来越站不住脚。原因有三：

**第一，技术领先越来越难以持久。**在第 2 章我们讨论过，模型能力正在快速同质化，开源模型的繁荣让强大的能力随处可得。一家公司的技术领先，可能在几个月内就被追平。当技术差距缩小时，用户靠什么来选择？靠品牌。

**第二，Agent 的购买决策高度依赖信任。**在第 6 章我们讨论过，信任是 Agent 的第一产品。而信任在很大程度上是由品牌承载的。客户把一项工作托付给一个 Agent，本质上是在托付给提供这个 Agent 的公司。一个值得信任的品牌，能够大大降低客户的决策门槛。

**第三，品牌能够承载溢价。**在价格战激烈的中国 AI 市场，品牌是少数能够支撑溢价的因素之一。客户愿意为一个信任的品牌多付一些钱，因为这降低了他们的风险。

观察全球领先的 AI 公司，会发现它们都在有意识地经营品牌。Anthropic 以"安全"和"负责任"作为品牌的核心，从公司的使命、研究方向、产品设计到对外沟通，都在一致地强化这一形象。这种品牌定位为它在企业市场和开发者市场赢得了独特的信任。OpenAI 则以"推动通用人工智能造福全人类"为使命，其产品发布总是能引发全球关注。国内的 DeepSeek 以"开源""极致的工程效率""专注研究"形成了鲜明的品牌形象，在全球开发者社区获得了广泛的尊重。

## 14.2 品牌的三个层次

Agent 公司的品牌可以分为三个层次：

### 第一层：公司品牌

公司品牌回答的问题是："**你是一家什么样的公司？**"它包括公司的使命、愿景、价值观、文化、创始人形象等。

对于 Agent 公司来说，公司品牌尤其重要，因为客户托付的对象最终是公司。客户会问：这家公司靠谱吗？它的价值观是什么？它会怎么对待我的数据？它会长期存在吗？

### 第二层：产品品牌

产品品牌回答的问题是："**你的产品是什么样的？**"它包括产品的名称、定位、个性、体验等。

对于 Agent 产品来说，产品品牌还有一个特殊的维度：**Agent 的"人设"**——它的性格、说话方式、工作风格。我们会在 14.4 节详细讨论。

### 第三层：品类品牌

品类品牌回答的问题是："**你代表了什么品类？**"当用户想到某个品类时，第一个想到的是你，你就拥有了品类品牌。

品类品牌是品牌建设的最高境界。在 Agent 领域，品类还在不断形成和分化中，这为新公司成为品类代表提供了机会。比如，"在终端里干活的编程智能体""在云端异步完成任务的编程智能体"这些品类，都有海外产品成为了早期的品类代表。在中国市场，各个细分品类的代表还在形成之中。

## 14.3 品牌叙事的核心：一个好故事

品牌建设的核心是**叙事**——你讲一个什么样的故事，让客户记住你、信任你、喜欢你。

### 好的品牌故事的要素

一个好的 Agent 品牌故事，通常包括以下要素：

**一个真实的问题。**故事从一个真实存在的、客户能够共鸣的问题开始。比如："每个程序员都有过这样的经历：明明是一个简单的 bug，却要花一下午在代码库里翻来翻去。"

**一个坚定的信念。**你对这个问题有什么独特的看法？你相信什么？比如："我们相信，程序员的时间应该花在创造上，而不是花在重复劳动上。"

**一个独特的方法。**你用什么独特的方法来解决这个问题？比如："我们打造了一个能理解整个代码库的 Agent，它不只是帮你写代码，而是像一个熟悉项目的同事一样工作。"

**一个可信的证据。**你凭什么让人相信你能做到？比如团队的背景、客户的成果、技术的突破。

**一个美好的愿景。**解决了这个问题之后，世界会变成什么样？比如："当每个程序员都有一个可靠的 AI 搭档，软件开发将变得更快、更好、更有乐趣。"

### 避免的叙事陷阱

**陷阱一：技术叙事。**只讲技术有多先进、模型有多强大、参数有多少。技术叙事对技术人员有一定吸引力，但很难打动更广泛的客户，而且容易被竞争对手追平。

**陷阱二：宏大叙事。**"重新定义生产力""开启 AI 新纪元""引领第四次工业革命"。这种宏大的叙事在 AI 行业泛滥成灾，已经让人审美疲劳，而且空洞无物。

**陷阱三：恐惧叙事。**"不用 AI 就会被淘汰""AI 将取代 XX% 的工作"。恐惧叙事在短期内能制造焦虑、推动购买，但长期来看会损害品牌形象，也会引发社会的反感和抵触。

**陷阱四：替代叙事。**"用 AI 取代员工""一个 Agent 顶十个人"。替代叙事在面向老板时可能有吸引力，但会引发员工的强烈抵触，也容易引起舆论争议。在中国，就业是一个高度敏感的社会议题，过度渲染"AI 替代人工"可能引发不必要的负面舆论。

### 推荐的叙事方向

**赋能叙事**：Agent 让人更强大，让人能做到以前做不到的事。"让每个人都拥有一个专业团队。"

**解放叙事**：Agent 把人从重复、枯燥的工作中解放出来，让人专注于更有价值、更有创造性的工作。"把时间还给创造。"

**协作叙事**：人与 Agent 是搭档，各自发挥所长。"你负责想清楚，它负责做出来。"

**托付叙事**：Agent 是一个值得托付的同事。"交给它，你可以放心。"

## 14.4 Agent 的"人设"

Agent 产品有一个传统软件没有的品牌维度：**Agent 本身的人设**。用户在与 Agent 交互时，会自然而然地感知到它的"性格"：它说话的语气、它处理问题的方式、它面对不确定时的态度、它犯错时的反应。

这个人设，是产品品牌的重要组成部分，也是用户体验的重要组成部分。

### Agent 人设的维度

设计 Agent 的人设，可以从以下几个维度考虑：

| 维度 | 一端 | 另一端 | 考虑因素 |
|---|---|---|---|
| **语气** | 正式、专业 | 轻松、亲切 | 目标用户、使用场景 |
| **主动性** | 被动等待指令 | 主动提出建议 | 任务类型、用户偏好 |
| **话量** | 简洁、只说必要的 | 详细、充分解释 | 用户专业度、任务复杂度 |
| **自信度** | 谦逊、经常确认 | 自信、果断执行 | 任务风险、用户信任程度 |
| **诚实度** | — | 坦诚说明不确定和局限 | 这一维度应始终保持在高水平 |
| **个性化** | 中性、标准化 | 鲜明的个性 | 品牌定位、用户群体 |

### 人设的设计原则

**原则一：与品牌定位一致。**面向企业和专业人士的 Agent，人设应该偏专业、可靠、克制；面向个人用户和年轻人群的 Agent，人设可以更轻松、更有个性。

**原则二：诚实是底线。**无论人设如何设计，诚实都应该是不变的底线。Agent 应该坦诚地说明自己不确定的地方、不能做的事情、可能犯的错误。一个"不懂装懂"的 Agent，无论多么讨人喜欢，最终都会失去用户的信任。

**原则三：可靠胜于讨喜。**对于需要托付工作的 Agent，用户最需要的是可靠，而不是讨喜。过度的热情、过多的赞美、刻意的幽默，在工作场景中可能显得不专业，甚至令人反感。

**原则四：适应用户和场景。**好的 Agent 人设应该能够适应不同的用户和场景。面对新手时多解释，面对专家时少啰嗦；处理简单任务时直接执行，处理高风险任务时谨慎确认。

### 关于"拟人化"的边界

在第 4 章，我们讨论了 Agent 定位中的拟人化问题。在品牌人设中，拟人化同样需要把握边界：

- **适度拟人化**能够增加亲和力，让用户更容易接受和使用 Agent。
- **过度拟人化**可能让用户产生不切实际的期望（"它应该像人一样理解我"），或者产生情感依赖，甚至引发伦理争议。

我们的建议是：**让 Agent 像一个专业、可靠的同事，而不是一个"人"。**它有自己的工作风格，但不假装有情感；它会礼貌地交流，但不刻意讨好；它会承认错误，但不过度道歉。

## 14.5 创始人品牌

在 AI 行业，创始人往往是公司品牌最重要的载体。一位有思想、有见识、敢表达的创始人，能够为公司带来大量的关注和信任。

### 创始人品牌的价值

- **注意力**：在信息过载的时代，人们更愿意关注"人"而不是"公司"。创始人的观点、经历、故事更容易引发关注和传播。
- **信任**：客户——尤其是企业客户——在选择一家创业公司时，很大程度上是在选择创始人。创始人的专业背景、价值观、远见，是客户信任的重要来源。
- **人才**：优秀的创始人品牌能够吸引优秀的人才加入。
- **资本**：创始人的影响力有助于融资。

### 创始人品牌的建设

- **找到自己的声音**：创始人应该在自己最擅长、最有洞见的领域发声。可以是技术、可以是行业、可以是创业经验、可以是对 AI 未来的思考。
- **持续输出**：在社交媒体、行业会议、媒体采访、播客等渠道持续输出观点。
- **真诚表达**：分享真实的思考、真实的经历，包括失败和挫折。
- **与公司品牌一致**：创始人的个人表达应该与公司的价值观和品牌定位一致。

### 创始人品牌的风险

- **言多必失**：创始人的不当言论可能给公司带来负面影响。在敏感话题上要格外谨慎。
- **过度依赖**：公司品牌过度依赖创始人个人，一旦创始人出现问题，公司品牌也会受到严重影响。
- **精力分散**：创始人花太多时间在个人品牌上，可能影响公司的经营管理。

## 14.6 品牌的视觉与语言

### 视觉识别

Agent 公司的视觉识别系统，需要传达出可信、专业、现代的形象。当前 AI 行业的视觉风格存在明显的同质化：深蓝色和紫色的渐变、发光的线条、抽象的大脑和神经网络图案、机器人形象……这些已经成为 AI 行业的"视觉陈词滥调"。

要想在视觉上脱颖而出，可以考虑：

- **避免陈词滥调**：不使用发光的大脑、机器人、蓝紫色渐变等泛滥的元素。
- **突出温度**：使用更温暖、更有人情味的色彩和图像，传达"为人服务"的理念。
- **展示真实**：在宣传中使用真实的产品截图、真实的用户场景、真实的工作成果，而不是抽象的概念图。
- **保持一致**：在所有触点上保持视觉风格的一致性。

### 品牌语言

品牌语言是品牌的"声音"——你用什么样的词汇、句式、语气来表达。对于 Agent 公司，建议：

- **说人话**：避免行业黑话和空洞的术语（"赋能""抓手""闭环""数智化"），用客户能理解的简单语言。
- **说具体**：用具体的场景、具体的数字、具体的结果，代替抽象的概念。
- **说真话**：不夸大、不回避、不绝对化。
- **有态度**：在保持专业的同时，有自己的观点和态度。

### 品牌语言指南

建议制定一份品牌语言指南，规范所有对外沟通的语言风格。指南可以包括：

- **品牌的语气**：比如"专业但不刻板，自信但不傲慢，友好但不随意"。
- **推荐使用的词汇**：比如"完成""交付""搭档""放心"。
- **避免使用的词汇**：比如"颠覆""革命""取代""最强""第一"等。
- **示例对比**：同一个意思的好表达和差表达。

## 14.7 品牌的一致性：每个触点都在讲故事

品牌不是由一则广告或一个口号建立的，而是由客户与公司的每一次接触累积而成的。对于 Agent 公司来说，品牌触点包括：

- **营销触点**：官网、广告、内容、社交媒体、活动。
- **销售触点**：销售人员的沟通、方案、演示、合同。
- **产品触点**：产品界面、Agent 的交互方式和人设、文档。
- **服务触点**：客户支持、客户成功、培训。
- **公共触点**：媒体报道、创始人言论、社会责任活动、危机处理。

每一个触点都在讲述品牌的故事。如果营销说"安全可靠"，但产品经常出错；如果销售说"以客户为中心"，但客服响应缓慢；如果创始人说"负责任的 AI"，但公司在数据使用上不透明——品牌故事就会崩塌。

**品牌一致性的关键是：品牌不只是市场部的事，而是整个公司的事。**每一位员工都应该理解公司的品牌定位和价值观，并在自己的工作中体现出来。

## 14.8 中国市场的品牌建设特点

### 特点一：媒体格局多元

中国的媒体格局非常多元：传统媒体、门户网站、垂直科技媒体、自媒体、短视频平台、社交平台……每一种媒体都有自己的影响力和受众。品牌建设需要在多个媒体渠道上协调一致地发声。

### 特点二："大厂光环"效应

在中国，大厂的品牌光环效应非常明显。很多客户——尤其是政企客户和传统企业——倾向于选择大厂的产品，因为"大厂靠谱""大厂不会倒闭""出了问题有人负责"。对于创业公司来说，需要通过其他方式建立信任：专业性、案例、资质、服务、生态伙伴的背书。

### 特点三：政策与社会议题的敏感性

AI 相关的话题在中国容易与政策、就业、安全、伦理等社会议题相关联。品牌传播要特别注意这些议题的敏感性，避免引发不必要的争议。

### 特点四：国产化与自主可控的叙事

在当前的国际环境下，"国产化""自主可控""中国自己的 AI"是一个有力的叙事方向，尤其是在政企市场。但这一叙事要基于事实，不要过度渲染，也不要贬低海外产品——专业的客户会做出理性的判断。

### 特点五：口碑的力量

在中国企业服务市场，口碑的力量极其强大。客户之间的推荐、行业圈子里的评价、社群中的讨论，往往比任何广告都更有影响力。品牌建设的根本，是**让每一个客户都满意**。

## 14.9 品牌的度量

品牌建设的效果难以直接衡量，但可以通过一些指标来跟踪：

- **品牌认知度**：目标客户中知道你的品牌的比例。
- **品牌联想**：目标客户提到你的品牌时，会联想到什么。这些联想是否与你的品牌定位一致？
- **品类关联度**：当目标客户想到某个品类时，是否会想到你？（比如，"提到 AI 财务对账，你会想到哪些品牌？"）
- **净推荐值**：客户向他人推荐你的意愿。
- **品牌搜索量**：直接搜索你的品牌名称的数量及其变化趋势。
- **媒体与社交声量**：你的品牌在媒体和社交平台上被提及的数量和情感倾向。
- **AI 回答中的品牌呈现**：在主流 AI 助手中询问相关问题时，你的品牌是否被提及、如何被描述。

建议每半年或每年进行一次品牌调研，系统地了解品牌的健康状况。

## 14.10 案例：一家 Agent 公司的品牌重塑

> 以下为综合化、匿名化案例，公司名为化名。

"灵犀智能"是一家做企业 Agent 平台的公司，成立三年，产品在技术圈有一定口碑。但公司的品牌形象一直比较模糊：官网上充斥着"赋能企业数智化转型""打造下一代 AI 原生应用"之类的空洞口号；视觉上是典型的蓝紫色渐变和发光线条；销售人员在客户面前讲的内容五花八门，有的强调技术、有的强调价格、有的强调服务。

**问题暴露**。在一次品牌调研中，团队发现：大部分目标客户没听说过灵犀；听说过的客户中，对灵犀的印象也很模糊，"好像是一家做 AI 的公司"；甚至有客户把灵犀和另一家名字相近的公司搞混了。

**重新思考**。团队花了两个月时间，重新思考公司的品牌定位。他们访谈了大量客户，问了一个问题："你为什么选择灵犀？"客户的回答出奇一致："因为你们靠谱。""出了问题你们的人会第一时间赶过来。""你们不会乱承诺，说能做到的都做到了。"

团队意识到，灵犀真正的品牌资产不是技术，而是"**靠谱**"——在一个充满夸大宣传的行业里，灵犀是那个说到做到的公司。

**品牌重塑**。基于这一洞察，灵犀进行了系统的品牌重塑：

1. **新的品牌主张**："说到做到的 AI。"
2. **新的品牌故事**：讲述灵犀如何坚持"不夸大、不回避、不放弃"的原则，陪伴客户把 Agent 真正用起来的故事。
3. **新的视觉形象**：放弃了蓝紫色渐变，采用了更沉稳、更温暖的色彩；官网上用真实的客户场景和产品截图代替抽象的概念图。
4. **新的品牌语言**：制定了品牌语言指南，清除了所有的空洞口号和夸大表述，代之以具体的场景和数据。
5. **"承诺清单"**：在官网上公开了一份"灵犀承诺清单"，包括"我们不会承诺做不到的事""我们会坦诚告诉你产品的局限""出了问题我们第一时间响应"等，并公开了服务响应时间的实际数据。
6. **内部统一**：对全体员工进行品牌培训，让每个人都理解并践行"说到做到"的品牌理念。

**效果**。品牌重塑一年后，再次进行的品牌调研显示：灵犀的品牌认知度有了显著提升；更重要的是，品牌联想变得清晰而一致——客户提到灵犀，第一个联想到的就是"靠谱""说到做到"。销售团队反馈，在客户面前讲"说到做到"的故事，比讲技术参数有效得多。

### 案例启示

1. **品牌的真正资产，往往藏在客户的评价里。**问问客户为什么选择你，答案可能会让你意外。
2. **在一个充满夸大的行业里，"诚实"和"靠谱"本身就是强大的差异化。**
3. **品牌重塑要系统进行**：主张、故事、视觉、语言、行为要一致。
4. **品牌是全公司的事**，需要每个员工践行。
5. **公开的承诺**能够有效地建立信任，但前提是你真的能做到。

## 本章要点

1. 随着技术同质化，品牌成为 Agent 公司的重要竞争力。品牌承载信任、支撑溢价。
2. 品牌有三个层次：公司品牌、产品品牌、品类品牌。品类品牌是最高境界。
3. 好的品牌故事包括真实的问题、坚定的信念、独特的方法、可信的证据、美好的愿景。避免技术叙事、宏大叙事、恐惧叙事、替代叙事；推荐赋能、解放、协作、托付叙事。
4. Agent 的"人设"是产品品牌的重要组成部分。诚实是底线，可靠胜于讨喜。让 Agent 像一个专业、可靠的同事，而不是一个"人"。
5. 创始人品牌在 AI 行业尤其重要，但要注意言多必失和过度依赖的风险。
6. 视觉上避免 AI 行业的陈词滥调；语言上说人话、说具体、说真话、有态度。
7. 品牌是由每一个触点累积而成的，品牌是整个公司的事。
8. 中国市场的品牌建设特点：媒体格局多元、大厂光环效应、社会议题敏感、国产化叙事、口碑的力量。
