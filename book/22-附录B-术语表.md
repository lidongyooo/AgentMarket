# 附录 B　术语表

> 本术语表收录了书中出现的主要术语，并注明首次详细讨论的章节，便于读者回查。

---

**AI 卓越中心（AI Center of Excellence）**
企业内部负责 AI 应用规划、推广、治理和经验沉淀的跨部门团队，是 Agent 在企业内部规模化推广的组织保障。（第 11 章）

**AI 生成内容标识**
按照相关规定，对 AI 生成合成的文本、图片、音频、视频等内容进行的显式标识和隐式标识。营销中使用的 AI 生成素材同样适用。（第 2 章）

**Agent / 智能体**
能够理解目标、拆解任务、调用工具、在环境中自主执行多步骤操作并交付结果的 AI 系统。本书将其概括为"会干活的 AI"。（第 1 章）

**Agent 九站旅程**
本书提出的 Agent 购买旅程：认知 → 兴趣 → 体验 → 试点上岗 → 评估 → 采购 → 规模化上岗 → 价值证明 → 续约与扩张。比 SaaS 多出"试点上岗"和"规模化上岗"两站。（第 3 章）

**Agent 就绪（Agent-ready）**
应用和服务提供能够被 Agent 调用的接口和文档，使 Agent 能够代替用户完成操作。（第 19 章）

**Agent 素养清单**
本书提出的十个问题，用于检验营销团队对自家 Agent 产品的理解程度。（第 1 章）

**Aha 时刻**
用户第一次真正体验到产品核心价值的瞬间。Agent 产品的 Aha 时刻是"首个完成任务"。（第 10 章）

**B2A（Business to Agent）营销**
面向 Agent 的营销。当 Agent 成为工具和服务的选择者时，通过高质量的机器可读文档、标准化接入、稳定可靠的服务来赢得 Agent 的"选择"。（第 19 章）

**变更前置时间**
软件交付效能指标之一，指从代码提交到部署上线所需的时间。（第 16 章）

**不负责的事**
Agent 岗位说明书中明确列出的工作边界。本书认为它比"负责的事"更能建立信任。（第 4 章）

**超级用户计划**
识别、认可并赋能社区中最活跃、最热心用户的计划，也称大使计划、布道师计划、KOC 计划。（第 9 章）

**过程可信**
可信三角之一，指客户相信 Agent 的工作过程是看得见、管得住、撤得回的。（第 6 章）

**黄金任务**
在频次、价值、可验证性、容错度四个维度上都得分高的任务，是 Agent 定位与首个场景选择的最佳起点。（第 4 章）

**混合计费**
组合使用订阅、用量、任务、结果等多种计费方式的商业模式，例如"基础订阅费 + 包含用量 + 超额按量计费"。（第 5 章）

**渐进式放权**
在信任建立过程中逐步提高 Agent 自主程度的路径：观察期 → 辅助期 → 监督期 → 授权期。（第 6 章）

**节省工时**
Agent 完成的工作如果由人完成所需的时间，减去人类的监督时间。是衡量 Agent 价值的常用指标，但应采用保守的测量方法。（第 16 章）

**准入门槛（政企）**
进入政企市场需要满足的条件，包括信创适配、等级保护、商用密码应用、离线私有化部署、模型备案、供应商资质等。（第 12 章）

**净交付价值（NDV）**
本书提出的 Agent 价值公式：净交付价值 = 任务价值 × 完成率 × 频次 − 监督成本 − 风险成本 − 使用成本。（第 1 章）

**净收入留存率（NRR）**
一组老客户在一年后的收入与一年前收入的比值，综合反映续约、扩张、降级和流失的效果。（第 15 章）

**可信三角**
本书提出的 Agent 信任模型：能力可信、过程可信、主体可信，三者缺一不可。（第 6 章）

**可验证性原理**
本书提出的规律：一项工作的结果越容易被验证，Agent 在这项工作上越容易被信任，也就越容易被卖出去。编程智能体最先跑通的根本原因在于代码可验证。（第 1 章）

**模型上下文协议（MCP）**
Anthropic 于 2024 年底开源的协议，旨在为 AI 模型连接外部工具和数据源提供通用标准，此后获得业界广泛跟进。（第 1 章、第 9 章）

**能力可信**
可信三角之一，指客户相信 Agent 能把事情做好。（第 6 章）

**前线部署工程师（Forward Deployed Engineer）**
深入客户现场，把产品能力转化为客户业务价值的工程师角色。在中国常由实施顾问或交付工程师承担。（第 11 章）

**人在回路（Human-in-the-loop）**
在 Agent 的工作流程中设置人工审核和决策环节的设计方式。Agent 负责执行，人负责决策和把关。（第 6 章）

**入职材料**
为 Agent 上岗准备的背景介绍、规范标准、操作手册、知识库、案例库和边界说明。本书认为 Agent 的表现有一半取决于入职材料的质量。（第 15 章）

**三段式 POC**
本书推荐的 POC 设计：对齐（成功标准书）→ 执行（快速迭代、紧密沟通）→ 复盘（价值报告）。（第 11 章）

**生成式引擎优化（GEO）**
让品牌和内容在 AI 助手生成的回答中被准确提及和引用的方法。应坚持做真正有价值的内容，避免操纵。（第 8 章）

**生成式人工智能服务备案/登记**
面向境内公众提供生成式 AI 服务时需要履行的监管手续。备案和登记情况是企业和政企客户关注的信任信号。（第 2 章）

**首个完成任务（FCT）**
用户交代的第一个任务被 Agent 成功完成且结果被采纳。首个完成任务率是 Agent 产品 PLG 的核心激活指标。（第 10 章）

**首战必胜**
Agent 企业销售的铁律：在企业客户中选择的第一个场景必须成功，它决定了后续能否扩展。（第 11 章）

**提示词注入（Prompt Injection）**
外部内容中包含恶意指令、诱导 Agent 执行危险操作的攻击方式。是 Agent 特有的安全风险之一。（第 6 章）

**万能的诅咒**
Agent 什么都能做，客户反而不知道用它做什么的现象。破解方法是主动收窄定位。（第 4 章）

**信创（信息技术应用创新）**
在关键领域推进信息技术自主可控，涉及国产芯片、操作系统、数据库、中间件和大模型等。是政企市场的重要准入要求。（第 12 章）

**信任中心（Trust Center）**
官网上集中展示安全、隐私、合规信息的专门页面。（第 6 章）

**效果漂移**
由于业务变化、数据变化等原因，Agent 的效果随时间逐渐下降的现象。（第 15 章）

**影子对手**
本书对海外标杆 Agent 产品在中国市场角色的描述：它们未在中国大陆正式提供服务，但在品类定义、期望设定和叙事参照上深刻影响中国市场。（第 2 章）

**用量焦虑**
按用量计费的产品中，用户担心费用和额度而降低使用意愿的心理。可以通过用量看板、任务前预估、温和限额处理等方式缓解。（第 5 章）

**岗位定位法**
本书推荐的 Agent 定位方法：像招聘员工一样，为 Agent 写一份岗位说明书。（第 4 章）

**监督成本**
人类为了让 Agent 完成任务而付出的时间和精力，包括描述任务、回答澄清、审核结果、纠正错误。是净交付价值公式中最容易被忽视的变量。（第 1 章）

**暗流量**
无法被数据追踪的营销流量，如私域传播、跨平台传播、线下影响、口碑推荐等。在中国企业服务市场中比例较高。（第 16 章）

**主体可信**
可信三角之一，指客户相信提供 Agent 的公司是可靠的、负责任的、合规的。（第 6 章）

**资质墙**
把公司所有的资质、认证、备案、荣誉、知名客户集中整理形成的标准化展示材料。（第 6 章）

**自主程度**
Agent 在没有人类确认的情况下独立执行操作的程度。自主程度越高，节省的人力越多，风险也越大。（第 1 章）

**采纳率**
Agent 完成的任务中，结果被用户接受并使用的比例。是衡量 Agent 工作质量的核心指标。（第 16 章）

**北极星指标**
反映产品核心价值、与长期商业成功高度相关的最重要指标。本书推荐 Agent 产品采用"每周被采纳的完成任务数"。（第 16 章）
