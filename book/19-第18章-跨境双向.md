# 第 18 章　跨境双向：海外 Agent 入华与中国 Agent 出海

> 跨境的最大成本不是翻译，也不是渠道，而是信任。

## 18.1 两个方向，一个核心问题

在 Agent 产业中，跨境发展有两个方向：

**入华**：海外的 Agent 产品和公司希望进入中国市场，或者以某种方式服务中国的用户和企业。

**出海**：中国的 Agent 产品和公司希望走向海外市场，服务全球的用户和企业。

这两个方向看起来截然不同，但它们面临一个共同的核心问题：**如何在一个陌生的市场中建立信任**。海外产品进入中国，需要让中国的用户、企业和监管部门信任它；中国产品走向海外，需要让海外的用户、企业和监管部门信任它。而在当前复杂的国际环境下，跨境信任的建立比以往任何时候都更加困难。

本章分别讨论这两个方向的营销策略。

## 18.2 海外 Agent 与中国市场：现实与路径

### 现实情况

首先需要明确当前的现实情况：

**头部海外模型厂商未在中国大陆正式提供服务。**Anthropic、OpenAI 等海外头部模型厂商，目前都没有在中国大陆正式提供面向公众的服务。部分厂商还对中国资本控股的企业设置了明确的服务限制。

**合规门槛很高。**在中国面向公众提供生成式 AI 服务，需要遵守《生成式人工智能服务管理暂行办法》等法规，完成备案或登记，落实内容安全、数据安全、个人信息保护、AI 生成内容标识等要求。如果涉及数据出境，还需要满足数据出境的相关规定。

**国内竞争激烈。**中国本土的 Agent 产品数量众多、迭代迅速、价格低廉，并且更了解本土用户的需求和本土的生态环境。

在这样的现实下，海外 Agent 产品想要直接进入中国市场、面向中国公众提供服务，面临极大的障碍。

### 海外产品对中国市场的间接影响

尽管海外头部 Agent 产品没有直接进入中国市场，但它们对中国市场的影响是深远的：

- **定义品类**：很多 Agent 品类的产品形态，是由海外产品率先定义的。中国的产品团队会研究和借鉴这些产品的设计理念。
- **设定期望**：中国的技术用户会关注海外产品的进展，并以此为参照来评价国内产品。
- **推动标准**：海外公司推出的开放协议（如 MCP）在中国也被广泛采用，影响着中国 Agent 生态的技术架构。
- **影响叙事**：海外公司的产品发布、技术突破、商业进展，会在中国的科技媒体和社交平台上被广泛讨论，影响中国市场对 Agent 的整体认知。

### 海外企业服务中国的可能路径

对于希望服务中国市场的海外 Agent 公司（尤其是那些不受上述限制的中小型 Agent 应用公司），可能的路径包括：

**路径一：本地化合作。**与中国本土的合规企业合作，由本土企业作为服务提供方，使用境内已备案的模型或合规部署的开源模型，结合海外公司的产品设计和技术经验，面向中国市场提供本地化的产品和服务。

**路径二：服务在华外资企业的内部场景。**部分在华外资企业有使用全球统一工具的需求。但即使是企业内部使用，也需要认真评估数据出境、网络安全等合规要求，不能想当然。

**路径三：技术授权与开源。**通过开源项目、技术授权等方式，让中国的开发者和企业使用其技术，由中国企业自主部署和运营。

无论选择哪条路径，**合规都是前提**。建议在进入中国市场之前，寻求熟悉中国 AI 监管的专业律师的意见，进行全面的合规评估。

### 对国内营销人的启示：如何面对"影子对手"

对于在中国市场销售 Agent 产品的营销人来说，海外标杆产品是一个绕不开的"影子对手"（见第 2 章）。用户会问："你们和 Claude 比怎么样？""能达到 Codex 的水平吗？"

面对这类问题，建议：

- **不回避，不贬低**：坦诚地承认海外标杆产品在某些方面的领先，同时不贬低它们。专业的用户会对贬低竞争对手的言论产生反感，而且这种言论也可能违反反不正当竞争的相关规定。
- **讲清楚差异化**：说明你的产品在哪些方面更适合中国用户——本土技术栈的支持、中文能力、本土系统的集成、合规与数据安全、本地化服务、价格等。
- **讲清楚可用性**：在合规的前提下，说明你的产品可以稳定、合规地在中国使用，满足企业的采购和合规要求。
- **用事实说话**：在用户关心的具体场景中，提供可验证的对比和案例，而不是笼统的宣称。

## 18.3 中国 Agent 出海：机遇与挑战

### 为什么要出海

越来越多的中国 Agent 公司选择出海，原因主要有：

**海外付费意愿更高。**相比国内市场，欧美等海外市场的个人和企业用户对软件订阅的付费意愿普遍更高，客单价也更高。

**避开国内的价格战。**国内 AI 市场的价格战非常激烈，大厂的免费产品让创业公司难以盈利。海外市场的竞争格局不同，给了中国创业公司更多的空间。

**全球化的视野。**AI 是一个全球化的产业，优秀的产品理应服务全球用户。很多中国团队从一开始就以全球市场为目标。

**中国团队的优势。**中国团队在产品迭代速度、工程效率、成本控制等方面有一定优势。

近年来，已经有不少中国团队打造的 AI 应用在海外市场取得了成功，在图像生成、视频生成、AI 写作、AI 搜索、通用智能体等领域都有代表性的产品，其中一些甚至在全球范围内产生了广泛影响。这些成功案例证明了中国 Agent 公司出海的可行性。

### 出海的主要挑战

**信任挑战。**在当前的国际环境下，"中国背景"可能会引发部分海外用户和企业对数据安全和隐私的担忧，尤其是在欧美的企业市场和政府市场。这是中国 Agent 公司出海面临的最大挑战。

**合规挑战。**海外市场有自己的监管体系：欧盟的《通用数据保护条例》（GDPR）和《人工智能法案》（AI Act），美国各州的隐私法和 AI 相关法规，以及各国的数据本地化要求、出口管制规定等。这些法规复杂且在不断变化。

**市场认知挑战。**中国团队对海外市场的用户需求、文化习惯、营销渠道往往缺乏深入了解，容易出现"用国内的方法做海外的市场"的问题。

**组织挑战。**时差、语言、文化、人才、管理等方面的挑战。

### 出海的市场选择

不同的海外市场有不同的特点：

| 市场 | 特点 | 适合的产品 | 主要挑战 |
|---|---|---|---|
| **北美** | 付费意愿最高，市场最大，竞争最激烈 | 面向开发者、专业人士、创作者的产品 | 竞争激烈，信任挑战大，获客成本高 |
| **欧洲** | 付费意愿较高，重视隐私和合规 | 合规能力强、重视隐私的产品 | 合规要求严格（GDPR、AI Act），多语言 |
| **日韩** | 付费意愿较高，对产品品质要求高 | 品质精良、本地化程度高的产品 | 本地化要求高，文化差异 |
| **东南亚** | 增长快，数字化程度提升中，华人基础 | 性价比高、移动优先的产品 | 付费能力有限，市场分散 |
| **中东** | 数字化投入大，政府推动 AI 发展 | 企业级、政府级解决方案 | 需要本地关系，文化差异 |
| **拉美** | 用户基数大，增长潜力大 | 移动优先、性价比高的产品 | 付费能力有限，支付基础设施 |

很多中国 Agent 公司选择以北美为首要目标市场，因为它是全球 AI 产品的风向标，在北美获得成功能够产生全球影响力。但北美市场的竞争也最激烈。另一种策略是从东南亚、日韩、中东等竞争相对缓和、对中国产品接受度较高的市场切入。

## 18.4 出海营销打法

### 产品层面：全球化设计

- **从第一天起就全球化**：产品的语言、设计、交互从一开始就面向全球用户，而不是从中文版本"翻译"过去。
- **深度本地化**：本地化不只是翻译，还包括对本地用户习惯、文化背景、使用场景的适配。
- **全球化的基础设施**：在目标市场部署服务器，满足数据本地化的要求，保证访问速度。
- **全球化的支付**：支持信用卡、主流的在线支付方式，以美元或当地货币定价。

### 渠道层面：海外的增长渠道

海外的增长渠道与国内有很大的不同：

- **产品发布平台**：Product Hunt 等产品发布平台，是新产品在海外科技圈获得初始关注的重要渠道。
- **技术社区**：Hacker News、Reddit 的相关板块、GitHub、Dev.to 等，是触达开发者的重要渠道。这些社区的用户同样有"反营销体质"，需要以真诚、有价值的方式参与。
- **社交媒体**：X（原 Twitter）在海外科技圈有很大的影响力，是创始人和产品发布消息、与用户互动的重要平台；LinkedIn 是触达企业用户和职场人士的重要渠道；YouTube 是教程和演示视频的主要平台。
- **社区平台**：Discord 是很多 AI 产品建设用户社区的首选平台。
- **内容创作者**：与海外的科技博主、YouTuber、播客主持人合作，是快速建立认知的有效方式。
- **搜索引擎优化**：在海外，搜索引擎优化（以及针对 AI 搜索的优化）仍然是获取长期流量的重要渠道。
- **应用商店**：对于移动端和桌面端产品，应用商店的优化同样重要。

### 内容层面：讲全球化的故事

- **讲用户的故事，不讲国别的故事**：海外用户关心的是产品能为他们做什么，而不是产品来自哪里。品牌叙事应该聚焦于用户价值。
- **原生的内容**：内容应该由熟悉目标市场的人来创作，用目标市场用户熟悉的语言风格和文化语境。
- **创始人的声音**：海外科技圈非常看重创始人的个人声音。创始人在社交媒体上分享产品理念、开发进展、行业思考，能够有效地建立信任和影响力。

### 信任层面：主动应对信任挑战

对于中国背景的 Agent 公司来说，主动应对信任挑战是出海营销的关键：

- **透明的数据政策**：清晰地说明用户数据存储在哪里、由谁处理、如何保护。对于欧美用户，数据存储在当地或可信的第三方云服务上，是建立信任的重要因素。
- **合规认证**：获得目标市场认可的安全和隐私认证，如 SOC 2、ISO 27001 等。
- **公司架构**：一些出海公司会在海外设立总部或主要运营实体，组建本地团队，以便更好地满足当地的合规要求和客户期望。这是一个需要综合考虑法律、税务、运营等多方面因素的战略决策，需要专业意见。
- **第三方审计**：邀请独立的第三方进行安全审计，并公开审计结果。
- **本地化的团队**：在目标市场组建本地的销售、客户成功和支持团队，让客户能够与"本地人"打交道。

### 合规层面：了解目标市场的规则

- **数据保护**：欧盟的 GDPR 对个人数据的处理有严格的要求；美国各州有各自的隐私法。
- **AI 监管**：欧盟的《人工智能法案》对不同风险等级的 AI 系统提出了不同的要求，相关义务正在分阶段生效；美国部分州也出台了 AI 相关的法规；其他国家和地区也在加快 AI 立法。
- **出口管制**：AI 相关的芯片、模型、技术可能受到出口管制规定的约束，需要了解相关规定。
- **中国的出境规定**：中国企业出海，同样需要遵守中国关于数据出境、技术出口等方面的规定。

建议在进入每一个目标市场之前，都寻求当地专业律师的意见。

## 18.5 双向的共同经验

无论是入华还是出海，跨境发展都有一些共同的经验：

### 经验一：合规先行

合规不是事后补救的事情，而是进入市场之前就必须解决的问题。在跨境场景中，合规问题往往更加复杂，涉及两个甚至多个国家和地区的法规。合规上的失误，可能导致业务被迫中断，甚至带来法律风险。

### 经验二：本地化不只是翻译

真正的本地化，包括语言、文化、用户习惯、生态系统、支付方式、营销渠道、客户服务等方方面面。很多跨境产品失败的原因，就是把本地化简单地理解为翻译。

### 经验三：信任是最大的成本

跨境发展最大的成本，是在陌生的市场中建立信任。这需要透明、合规、本地化的团队、本地的客户案例、持续的投入和耐心。

### 经验四：尊重当地的竞争者

无论在哪个市场，当地的竞争者都更了解本地的用户和生态。跨境产品不应该低估当地的竞争者，而应该找到自己独特的价值。

### 经验五：保持战略定力

国际环境复杂多变，跨境发展会面临很多不确定性。需要在保持灵活应变的同时，保持战略定力，不因一时的困难而轻易放弃，也不因一时的成功而盲目扩张。

## 18.6 案例：一款中国编程工具的出海之路

> 以下为综合化、匿名化案例，公司名为化名，数字为示意。

"码帆"是一家中国团队开发的 AI 编程工具，最初面向国内开发者。在国内市场积累了一定用户后，团队决定出海。

**第一次尝试：失败**。团队第一次出海时，基本上是把国内的产品翻译成英文，在海外的社交媒体上投放了一些广告，结果效果很差：注册用户很少，留存率很低，付费转化几乎为零。团队分析了原因：产品的英文界面和文档翻译生硬；默认集成的都是国内的工具和平台，海外开发者用不上；在海外技术社区中没有任何存在感；一些海外用户在社区中质疑"数据会不会传回中国"，团队没有给出清晰的回应。

**第二次尝试：重新开始**。团队痛定思痛，决定以一种完全不同的方式重新出海：

1. **组建海外团队**：招聘了几位熟悉海外开发者社区的成员，负责产品本地化、社区运营和内容创作。
2. **产品重构**：重新设计了产品的英文版本，深度集成了海外开发者常用的工具和平台；文档由英语母语的技术写作者重写。
3. **数据透明**：海外版本的服务部署在海外的云服务商上，用户数据存储在海外；在官网上发布了清晰的数据政策，说明数据的存储位置和处理方式；启动了国际通行的安全认证。
4. **社区先行**：创始人开始在海外社交媒体上以个人身份分享产品开发的心得和对 AI 编程的思考；团队在技术社区中真诚地参与讨论，回答问题，而不是发广告；开源了产品的部分核心组件。
5. **聚焦细分**：没有试图在通用 AI 编程工具市场与海外巨头正面竞争，而是聚焦于一个细分场景——帮助开发者理解和维护陌生的大型开源项目代码库。这是团队在国内市场中积累的优势场景。
6. **产品发布**：在做好充分准备之后，团队在产品发布平台上正式发布了海外版本，配合创始人的社交媒体分享和社区的口碑传播，获得了不错的关注。

**结果**。第二次出海一年后，码帆的海外用户数量超过了国内用户，海外收入成为公司收入的主要来源。在海外开发者社区中，码帆在"理解大型代码库"这一细分场景中建立了一定的口碑。

### 案例启示

1. **出海不是翻译**，需要从产品、团队、渠道、内容全方位地本地化。
2. **数据透明**是中国背景公司出海建立信任的关键。
3. **社区先行**，以真诚的方式参与海外技术社区。
4. **聚焦细分场景**，避免与海外巨头正面竞争。
5. **本地化的团队**是出海成功的组织保障。
6. **失败是学习的机会**，第一次出海的失败为第二次的成功积累了经验。

## 本章要点

1. 跨境发展的两个方向——入华和出海——面临一个共同的核心问题：如何在陌生的市场中建立信任。
2. 海外头部模型厂商未在中国大陆正式提供服务，部分厂商对中国资本控股企业有服务限制；中国的合规门槛高，本土竞争激烈。海外产品对中国市场的影响主要是间接的：定义品类、设定期望、推动标准、影响叙事。
3. 海外企业服务中国的可能路径包括本地化合作、服务在华外企内部场景、技术授权与开源，合规是前提。
4. 国内营销人面对"影子对手"：不回避不贬低，讲清楚差异化和可用性，用事实说话。
5. 中国 Agent 出海的动力：海外付费意愿高、避开国内价格战、全球化视野、中国团队的优势。主要挑战：信任、合规、市场认知、组织。
6. 出海营销打法：全球化的产品设计、海外的增长渠道、全球化的故事、主动应对信任挑战、了解目标市场的规则。
7. 双向的共同经验：合规先行、本地化不只是翻译、信任是最大的成本、尊重当地竞争者、保持战略定力。
